How to check a Bitcoin bridge’s collateralization before using it

Learn how to check a Bitcoin bridge’s collateralization by matching each Locker’s collateral to its obligations, then compare the ratio with any published threshold.

The Crypto Front Page DeskNov 21, 2026 · 08:57 UTC4 min read

A Bitcoin bridge has measured collateral coverage when each Locker’s collateral is worth more than the obligations it backs. To check it, match the Locker’s assets to its outstanding obligations, value both at the same timestamp, and calculate the ratio.

  • Collateralization ratio = collateral value ÷ backed obligations × 100%.
  • Assess each Locker before relying on a system-wide total.
  • Compare the snapshot with any liquidation threshold the protocol publishes.

A bridge can issue a wrapped Bitcoin asset when a user moves value across chains. With TeleSwap, Lockers hold collateral, including TST, while teleBTC is a wrapped Bitcoin asset issued through the service. That makes TeleSwap locker versus contract risk a useful distinction: its collateralized Lockers make coverage a concrete question, while the bridge’s Bitcoin light client verifies Bitcoin data on-chain.

Measure collateral against the obligations it backs

A bridge collateral ratio tells you how the value pledged for a specific set of obligations compares with the obligations’ value. At 100%, the measured collateral and obligations are equal; above 100%, collateral value exceeds those obligations at that snapshot.

The key is to pair like with like. For a Locker, identify its collateral balance and the Bitcoin obligations assigned to it. Convert both into the same unit of value using a stated price source and timestamp. Then divide collateral value by obligation value and multiply by 100.

Take a Locker with $150 of collateral backing $100 of obligations. Its snapshot ratio is 150%. That figure can fall if the collateral price drops, or if new obligations are added while collateral stays the same. Prices and balances move, so the ratio describes a moment, not a permanent condition.

A system-wide ratio can conceal a weak Locker. Suppose one Locker has collateral worth $50 against $100 of obligations, while another has $250 against $100. Together, they hold $300 against $200, or 150% coverage. Yet the first Locker is only 50% covered. If obligations are tied to individual Lockers, excess collateral in the second does not by itself show that the first Locker can meet its own obligations. Use the individual figures to find that gap, then use the aggregate to understand overall coverage.

Find the inputs and calculate a current snapshot

To assess a bridge in practice, start with the specific bridge and Locker or pool you want to evaluate. Use the protocol’s official documentation or contract addresses to identify the relevant contracts, and a block explorer to inspect balances and transactions. A dashboard can help, but check which contracts and data it represents.

  1. Locate the Locker’s collateral balance and outstanding obligations. Confirm which obligations the collateral is assigned to cover.
  2. Find the collateral and Bitcoin prices, their source, and the time or block they represent. Value both balances at the same timestamp; mixing prices from different times can distort the comparison.
  3. Calculate the ratio, then compare it with the protocol’s published liquidation threshold, if one is available. The threshold gives context for when the protocol may act on a Locker’s collateral.
  4. Repeat the calculation for other Lockers. Review the system-wide figure after checking the individual coverage.

For a simple attempt, imagine the explorer shows one Locker with $150 of TST collateral and obligations worth $100 at the same block. The state after step one is a matched pair: $150 and $100. After step two, both are valued using the same stated price snapshot. The calculation gives 150%. If the protocol publishes a threshold, compare this result with it; if not, report the ratio without inventing a cutoff. Recheck later, because a price move or new obligations can change the result.

Coverage is one part of assessing a bridge’s payout risk. Contract security, custody arrangements, and price-feed reliability need separate review: a ratio measures the value of collateral against obligations, while those other factors affect how the system operates and how dependable its inputs are.

Related

What does a bridge collateral ratio mean?

A bridge collateral ratio is the value of assets pledged against specified obligations, expressed as a percentage. It is meaningful only when the collateral and obligations are correctly matched and measured at a clear time.

What is the difference between collateral and reserves in a crypto bridge?

Collateral is pledged to back particular obligations. Reserves may describe assets held across a system; check the protocol’s definition to see whether those assets are assigned to specific obligations or simply counted in a total.

The deciding figure is each Locker’s collateral value compared with the obligations it backs at the same snapshot. Check that ratio and its threshold, then watch the prices and balances that can change it.
