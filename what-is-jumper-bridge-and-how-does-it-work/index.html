What Is Jumper Bridge, and How Does It Work?

What is Jumper bridge used for? It routes token transfers and swaps across chains through LI.FI, whose Diamond contract executes the selected route.

The Crypto Front Page DeskNov 28, 2026 · 06:40 UTC3 min read

Jumper bridge is used to move or swap tokens between blockchains by routing a transaction through bridges and decentralized exchanges. At Jumper bridge, LI.FI assembles the route that carries out that transfer. The key detail for a DeFi user is that the LI.FI Diamond contract is the on-chain entry point for execution.

Take a cross-chain swap from ETH on Base to SOL on Solana. LI.FI’s routing API and SDK can combine a swap on the source chain, a bridge transfer, and a swap on the destination chain into one route. Same-asset bridging, such as moving a token between networks, is another use; so is a swap that stays on one chain.

LI.FI builds a route, then the Diamond executes it

LI.FI builds a route by combining bridge and DEX tools into ordered steps. Its API returns ranked route options, and each step identifies the bridge or exchange tool it uses. The user can compare the proposed routes before submitting one.

For the Base-to-Solana case, a route might name a DEX for the source-chain swap, a bridge such as Across or Stargate for the cross-chain transfer, and a destination swap. Those names describe possible route tools; the returned steps show which tools a particular route uses. Across, for instance, uses relayers that deliver tokens on the destination chain after a user initiates a transfer on the source chain. Across’s documentation describes that relayer role.

Once the route is selected, the wallet submits its transaction to the LI.FI Diamond contract. The Diamond dispatches calls to the relevant bridge or DEX facets, which contain the tool-specific logic. EIP-2535 describes this pattern: a Diamond contract routes function calls to facets, while keeping a single contract address as the entry point. EIP-2535 defines the Diamond structure, and LI.FI’s contract documentation describes its use of the pattern.

Think of the Diamond as a building’s reception desk: it directs each request to the right specialist department. The analogy stops at dispatch; the contract is executing blockchain calls, not passing messages between people.

The route’s output is the requested token in the destination wallet. The bridge and exchange calls are composed into the route, but each step still depends on the named tool and its on-chain execution.

Who runs Jumper bridge?

Jumper bridge is built on LI.FI’s routing API and SDK, while LI.FI’s Diamond contract provides the on-chain execution entry point. The route itself can call separate bridge and DEX protocols, so the Diamond coordinates the calls rather than replacing those tools.

Can Jumper bridge swap on a single chain?

Yes, Jumper bridging can include same-chain swaps as well as cross-chain transfers. A same-chain swap uses the route’s exchange steps without a bridge transfer; a cross-chain swap can combine exchange steps with a bridge step.

For an ERC-20 route that requires an allowance on an EVM source chain, review the approval address shown in the transaction: it should identify the LI.FI Diamond contract that will execute the route. That is the allowance to review or revoke afterwards. The bridge named in a route may be Across, Stargate, Circle CCTP, or another tool; the approval to inspect is the Diamond address shown in the approval.
