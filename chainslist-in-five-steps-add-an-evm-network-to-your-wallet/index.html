chainslist in Five Steps: Add an EVM Network to Your Wallet

chainslist passes an EVM network’s chain ID and RPC settings to a wallet; five checks show how to find the right chain and confirm the connection.

The Crypto Front Page DeskOct 21, 2026 · 11:03 UTC4 min read

chainslist helps add an EVM network by passing its settings to a compatible wallet, which then asks you to approve the change. The network is the blockchain the wallet will read from and send transactions to; the wallet remains the place where your accounts and keys are managed. The steps are to find the intended chain, check its details, connect your wallet, approve the request and confirm the selected network. The process changes the wallet’s network settings; it does not move funds.

What does chainslist do when you add a network?

chainslist matches a network entry with the settings a wallet needs to communicate with that chain. Those settings include a chain ID, which identifies the network to the wallet, and an RPC URL, the endpoint the wallet contacts to request data or submit a transaction. A network may also specify a display name and native currency symbol.

You can look up a network on chainslist and connect a compatible wallet so its network details can be sent for approval. Think of the RPC endpoint as a service desk: it carries requests between the wallet and the chain, while the chain ID tells the wallet which network those requests concern. Adding the settings makes that connection available in the wallet; it does not bridge assets from another chain or automatically add every token to the wallet’s display.

How do you find the right EVM network?

Search for the network by its recognized name, then compare the result with the network named by the app or service you intend to use. Similar names can refer to different networks, so check the chain ID and whether the entry is for a mainnet or a testnet before proceeding. A testnet is for testing and is separate from the network used for ordinary transactions.

Use these five steps to add the network:

  • Find it: Search for the network name, and confirm that the result matches the intended chain.
  • Check it: Review the chain ID, network type and native currency shown in the entry.
  • Connect: Choose your wallet and approve the connection request in the wallet interface.
  • Add it: Select the network’s add option, then review the proposed settings in the wallet.

The connection request and the add-network request are separate decisions: connecting lets the page communicate with the wallet, while adding asks the wallet to save network settings. The wallet’s own confirmation screen is the final point to review the chain name and details. If you prefer not to connect, many wallets let you enter network settings manually; compare each field with a source you trust.

What should you check after adding the network?

After approval, select the new network in the wallet and check that its name and currency match the entry you chose. That confirms the wallet has switched its active network setting, but it does not prove that every service or RPC endpoint will respond correctly. If the wallet shows an error or the details differ from what you expected, stop before signing a transaction and recheck the network information.

Adding a chain also does not change the address format into a separate account: an EVM wallet can use the same account address on more than one EVM network, while balances and transaction history belong to their respective chains. A token held on one network does not become available on another just because both are EVM-compatible. To use funds across networks, a separate transfer or bridge process may be needed.

The change is a saved network connection in the wallet. Next, check that the selected chain is the one your intended app expects, and verify its displayed network details before you approve transactions there.
