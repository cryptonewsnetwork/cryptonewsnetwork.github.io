Chainlist Add to MetaMask Button Does Nothing? Get the Prompt

The Crypto Front Page DeskNov 24, 2026 · 01:12 UTC2 min read

After clicking Add to MetaMask on Chainlist and seeing no response, you likely have a request waiting inside MetaMask or a different wallet answering the click. The Chainlist network directory illustrates the flow: its add-network button uses wallet_addEthereumChain to ask a compatible wallet to save EVM network details. First, the directory asks to connect to your wallet. MetaMask must be open and unlocked for you to handle that connection request. Open its extension icon to find the prompt, or select MetaMask if another wallet appears.

Start with the MetaMask icon in your desktop browser’s toolbar. A locked extension or closed popup can leave the connection request waiting out of sight while the page appears idle. Click the icon, unlock MetaMask, and look for the request to connect. Approve it, then return to the page and watch for a separate add-network request. Review the chain ID, RPC URL, and native currency in the wallet before approving that request.

An approval request that appears when you open MetaMask is the telltale sign: the button worked, but the prompt was hidden. Wallet requests remain pending until you approve or reject them. Finish the waiting request in the extension window before clicking the page’s button again. If you close the popup, reopen MetaMask from the toolbar to find it.

If Rabby Wallet appears instead, another installed wallet answered the click. Select MetaMask in the connect dialog. If you cannot choose a wallet there, temporarily disable Rabby in your browser’s extension settings, reload the directory page, and connect with MetaMask. A silent MetaMask alongside an active prompt in Rabby points to this cause.

The network may also be saved already. In that case, MetaMask can switch to it without showing a new add prompt. Open MetaMask’s network menu and see whether your intended network is active. If it is, you are done. If it is not, reload the directory page, click Connect Wallet first, and retry the add action.

If no wallet shows a request and the network has not changed, make sure MetaMask is enabled and opens from your browser toolbar. Reload the page with MetaMask unlocked, connect, and try once more. If no request reaches the wallet, use MetaMask’s manual add-network option with the chain ID, RPC URL, and native currency you have confirmed from the network’s own published information.
