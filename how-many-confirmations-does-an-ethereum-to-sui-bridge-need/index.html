How Many Confirmations Does an Ethereum-to-Sui Bridge Need?

How many confirmations does an Ethereum-to-Sui bridge need? Suibridge uses a configurable depth, then validators process the message before tokens reach your Sui wallet.

The Crypto Front Page DeskNov 27, 2026 · 12:19 UTC4 min read

An Ethereum-to-Sui bridge needs the confirmation depth set by its bridge validator committee; Suibridge’s live requirement can change, so there is no fixed count to memorize.

Ethereum confirmations are blocks added after your deposit

When you deposit a supported asset on Ethereum, the transaction is included in an Ethereum block. Each later block built on top of that block adds one confirmation. You do not need to approve a separate action for each confirmation; the Ethereum network adds blocks as it continues processing transactions.

Take an illustrative deposit included in block 100. If the bridge’s configured depth is N confirmations, it waits for the required blocks to build on top of block 100. N is a variable in this example, not a promised live count. The required depth is configurable and set by the bridge validator committee, so check current bridge status or documentation for the setting in force.

That waiting period gives the deposit time to become harder to reverse in an Ethereum chain reorganization. A reorganization can replace recent blocks with a different chain history. Waiting for more blocks before acting helps protect the bridge from treating a deposit as settled when its block is later removed from the canonical chain.

The stages also help explain what a status means while you wait. A deposit that has reached the Ethereum threshold has passed the Ethereum confirmation stage. The bridge message still needs processing before the destination asset is minted on Sui. Suibridge’s transfer states from Ethereum to Sui add context on how an app can describe those stages while the transfer moves forward.

Reaching the threshold does not mean the tokens are in your Sui wallet

Once the required Ethereum blocks have built on top of the deposit, Sui validators still process the bridge message. The destination step follows the Ethereum wait: the bridge processes the message and the supported asset is minted on Sui. Until that step completes, the Ethereum confirmation count alone is not proof that the token has arrived.

In practice, keep the deposit and the destination receipt distinct. You can see the Ethereum transaction included in block 100 and later observe that it has the configured number of confirmations. That changes the status of the source-chain stage; it does not change what is already visible in your Sui wallet. After Sui-side processing and minting, check the wallet for the resulting token or transfer record. The wallet receipt is the useful sign that the destination stage has completed.

This distinction matters when you are new to bridges because “confirmed” can sound like “delivered.” Here, it means Ethereum has supplied the required later blocks. The bridge still has work to do on Sui, so allow for that separate processing step before expecting the token in the wallet.

There is also a trust detail behind that processing. Suibridge does not use a separate guardian network: its bridge signers are Sui validators weighted by stake. The trust assumption is therefore Sui’s consensus. Ethereum confirmations protect the deposit against source-chain reorganizations; the Sui validator set handles the bridge message and destination-side processing.

Related

Do Ethereum confirmations guarantee that bridged tokens have arrived on Sui?

No. Confirmations show that the Ethereum deposit has reached the configured depth. Sui validators must still process the bridge message, and the resulting token must be minted on Sui. Check your Sui wallet for the completed transfer rather than treating the source-chain count as receipt.

Why can two bridges use different Ethereum confirmation counts?

Each bridge can set its own confirmation depth and may change that setting. The count reflects the bridge’s configured threshold for waiting on Ethereum, not a universal number every bridge must use. For an Ethereum-to-Sui transfer, consult the current bridge status or documentation for the committee-set depth. Then watch for Sui-side completion in your wallet: the deposit has moved from Ethereum to Sui only when that destination step finishes.
