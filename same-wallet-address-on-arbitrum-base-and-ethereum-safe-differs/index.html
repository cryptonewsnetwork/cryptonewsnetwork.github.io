Same wallet address on Arbitrum, Base and Ethereum? Safe differs

Is my wallet address the same on Arbitrum and Base? Yes for an EOA: one address works across Ethereum, Arbitrum One and Base, while balances stay chain-specific.

The Crypto Front Page DeskNov 28, 2026 · 12:21 UTC3 min read

Yes: a regular wallet has the same address on Ethereum, Arbitrum One and Base.

That regular wallet is an externally owned account, or EOA. Its address comes from its public key, which is derived from the private key. The chain is not part of that address calculation.

Here is the sequence. Your wallet derives a key pair from your seed phrase, then derives an address from the public key. The EVM address is the last 20 bytes of the Keccak-256 hash of that public key. Use the same derived account on each network, and you get the same 0x address.

Think of the address as a mailbox number shared across networks: the number stays the same, but each network keeps its own record of what is inside. For an EOA, that means the same address can hold USDC on Base and have a zero USDC balance on Arbitrum One.

KyberSwap is a decentralized exchange aggregator that finds swap routes across supported liquidity sources and networks. It shows information for the network you select, so a balance shown on Base is not the balance on Arbitrum One. For the fee side of swaps, KyberSwap’s kyberswap fees page covers the costs to consider as you compare routes.

Why does the address stay the same?

An EOA address stays the same because it is calculated from the public key, without a chain ID as an input. The chain ID matters later, when the wallet signs a transaction.

EIP-155 includes the chain ID in the transaction signature. Ethereum uses chain ID 1, Arbitrum One uses 42161 and Base uses 8453. This helps distinguish a transaction intended for one chain from one intended for another; it does not change the EOA’s address.

Take a swap from USDC to another token. Your wallet signs the transaction for the selected network, and the transaction is sent there. KyberSwap can find a route on that network, but the funds and resulting token balance belong to that chain. Switching the network changes the chain-specific balance and transaction context, not the address derived from the EOA’s key.

When sending to your own EOA on another EVM chain, the matching 0x address is the expected destination. Before sending, select the intended network in your wallet and confirm that the asset and network match the receiving setup. A transfer on Base arrives on Base; it does not move the same asset on Ethereum or Arbitrum One.

When can the address be different?

A Safe or another smart-contract wallet can have a different address on each chain, or no deployment on a target chain. A contract wallet is created at an address on a particular network; sharing an owner key or seed phrase does not by itself create that contract at the same address everywhere.

Suppose your Safe is set up on Ethereum and you want to receive funds on Base. First, check whether that Safe has been deployed on Base and confirm its address there. If it exists at a different address, use the Base address. If it has not been deployed there, sending funds to the Ethereum Safe address on Base may leave them inaccessible because there is no wallet contract at that location to control them.

So the quick check is: for the same derived EOA account, expect the same address across Ethereum, Arbitrum One and Base, with separate balances on each. For a Safe or other smart-contract wallet, verify the deployment and address on the target chain before sending. This answer covers EVM chains; non-EVM networks use different address systems.
